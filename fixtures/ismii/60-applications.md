# Applications

## Social

- **Avatars:** use the compact register (`ismii-avatar-*`) on every platform; feeds render avatars at 32 to 48px. The detailed full-rosette avatar is for places where the avatar shows large. Sandstone is the default ground. *Brand pack.*
- **Banners and link previews:** use the supplied files for X, LinkedIn, YouTube and Facebook, and set the Open Graph card as `og:image` and `twitter:image`.
- **Posts:** build on the post frames. Choose the ivory frame for text-led posts and the sandstone frame for announcements.

## Web

```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon-180.png">
```

Use `marble-ivory` for the page ground, `india-ink` for text, `deccani-teal` for links, and Sandstone Red for the signature and primary headings. *Proposed:* primary buttons in Sandstone Red with ivory text, square corners.

## Lecture and event posts

*Proposed.* One structure for every event: a `label` eyebrow (ISMII LECTURE, ISMII SEMINAR), the title in Cormorant `display`, the speaker and affiliation in Libre Franklin, then date, time and venue or Zoom in `caption`, all above the gold rule. Speaker photographs sit in a square crop with no border. See the Lecture post card.

## Print and ceremony

The stacked lockup and the seal belong to ceremonial print: certificates, programmes, colophons, lecture backdrops. The seal appears once per document, never alongside the full mark on the same face.

## Film

*Proposed.* The stacked lockup on India Ink is the end card, followed by the affiliation line. Lower-thirds set the name in Libre Franklin 600 and the role in Libre Franklin 400, ivory on a flat ink band with a gold rule above. On-screen source citations use `caption`.
