# Mark

- `ismii-mark-sandstone.svg`, `-ink.svg`, `-ivory.svg`: the full mark. Use above 40px.
- `ismii-mark-compact-*.svg`: compact register with a single aperture. Use at 40px and below.
- `ismii-seal.svg`: ceremonial seal for certificates and colophons. Not for interface.

All are outlined SVGs and true knockouts: the rosette shows the ground behind it. PNG exports at 512, 1024 and 2048px are in the original brand pack.
