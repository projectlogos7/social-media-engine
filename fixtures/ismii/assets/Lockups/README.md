# Lockups

- `horizontal-*`: the official signature. `stacked-*`: ceremonial and centred compositions.
- `full-colour` on ivory and light grounds; `reversed` on India Ink; `mono-ink` for single-colour print and embossing; `mono-ivory` on Sandstone Red, Deccani Teal and photography.
- Clear space: half the mark's height on every side. Minimum horizontal width 160px or 40mm.
